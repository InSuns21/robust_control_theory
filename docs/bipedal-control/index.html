BIPEDAL CONTROL LAB

倒れずに二足で歩く制御

「立つだけで不安定」から始めて、足首制御、ZMP、LIPM、Capture Point、ステップ回復までをブラウザで触って理解する。

まず結論

二足歩行は、倒れない姿勢を固定する問題ではありません。倒立振子のような不安定系を制御しつつ、必要なら次の足を置いて支持領域そのものを動かす問題です。

倒立振子→PD制御→ZMP制約→LIPM→Capture Point→歩行

LAB 1

倒立振子：立っているだけで不安定

STABLE? θ = 0.0° θ̇ = 0.00 rad/s
θ¨ = (g/l) sin θ + u
u = clamp(-Kp θ - Kd θ̇)

制御を OFF にすると数度の傾きでも増幅します。Kp を下げても同じ。入力上限があるため、大外乱はゲインだけでは救えません。

青い点が Capture Point。これが足裏から外れると、現在の足だけでは戻しにくくなります。Auto step を切って Big push を試してください。

WHAT TO NOTICE

この実験で見てほしい3点

  1. 不安定性：重心が足より前に出ると、そのまま前へ加速する。
  2. 入力制約：ZMP は足裏の外へ自由には置けない。制御入力は必ず飽和する。
  3. 支持領域の移動：大外乱では「もっと強く制御」ではなく「次の足を出す」が必要になる。

数式の導出、ZMP と支持領域、Capture Point の意味、実機で省略しているものはリポジトリの bipedal-control/README.md にまとめています。
